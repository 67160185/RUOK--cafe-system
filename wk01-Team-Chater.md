## 2. องค์ประกอบระบบเบื้องต้น

  -----------------------------------------------------------------------
  องค์ประกอบ                           รายละเอียด
  ----------------------------------- -----------------------------------
  People                              เจ้าของร้าน, บาริสต้า, พนักงาน, แคชเชียร์,
                                      พนักงานคลัง, ลูกค้า

  Process                             รับออเดอร์ → ชำระเงิน → ชงเครื่องดื่ม →
                                      เสิร์ฟ → จัดการสต็อก → สรุปยอดขาย

  Data                                ข้อมูลเมนู, ราคา, รายการสั่งซื้อ,
                                      ข้อมูลลูกค้า, สต็อกวัตถุดิบ, ยอดขายรายวัน

  Hardware                            คอมพิวเตอร์, แท็บเล็ต, POS,
                                      เครื่องพิมพ์ใบเสร็จ, เครื่องสแกน QR,
                                      เครื่องรูดบัตร

  Software                            POS, ระบบสต็อก, ระบบสมาชิก,
                                      โปรแกรมบัญชี, Grab, LINE MAN,
                                      foodpanda

  Network                             Wi‑Fi, Router, Cloud, การเชื่อมต่อ POS
                                      และระบบชำระเงิน
  -----------------------------------------------------------------------
