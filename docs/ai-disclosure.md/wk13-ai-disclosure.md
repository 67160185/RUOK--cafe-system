# AI Disclosure — Coding Sprint 3 (Week 13)

## 1. ข้อมูลการใช้ AI

- **โครงงาน:** RUOK Cafe System
- **Sprint:** Coding Sprint 3 — Integration และ End-to-End Testing
- **เครื่องมือ AI:** Copilot ใน VS Code (AI coding assistant)
- **ขอบเขตการเปิดเผย:** เอกสารนี้บันทึกการใช้ AI ที่เกิดขึ้นและตรวจสอบได้ใน repository รอบนี้ หากสมาชิกใช้ AI หรือเครื่องมืออื่นเพิ่มเติม ควรใส่ข้อมูลส่วนนั้นก่อนส่ง

## 2. วัตถุประสงค์ในการใช้ AI

ใช้ AI ช่วยหาสาเหตุที่คำสั่งรันโปรเจกต์หา `src/app.js` ไม่พบ ตรวจสอบพาธที่เกี่ยวข้องกับชุดทดสอบ และรันทดสอบอีกครั้งหลังแก้ไข

## 3. งานที่ AI ช่วย

- วิเคราะห์ error `MODULE_NOT_FOUND` และพบว่าไฟล์โปรเจกต์กับ dependency อยู่ใน `code/` แต่ `src/` อยู่ที่ราก repository
- ตรวจสอบแล้วว่าไม่มีชื่อไฟล์หรือโฟลเดอร์ปลายทางซ้ำ ก่อนย้ายเนื้อหาจาก `code/` กลับมายังราก repository เพื่อให้เรียก `npm run dev` และ `node src/app.js` จากตำแหน่งเดิมได้
- ปรับพาธใน `test/openapi.test.js` ให้ตรงกับโครงสร้างโปรเจกต์ โดยอ้างถึง `src/utils/validate.js`, `src/config/db.js` และ schema ใน `docs/wk07-schema.sql`
- รัน `npm test` ตรวจว่า Backend เริ่มทำงานและตอบ HTTP ได้ รวมถึงลองเปิด Backend และ Frontend ด้วยพอร์ตทดสอบที่ว่าง
- ช่วยร่างและปรับเอกสารของโครงงาน เช่น README และเอกสาร Usability Testing โดยอ้างอิงไฟล์และรายงานที่มีใน repository

## 4. งานที่ AI ไม่ได้ทำ

- AI ไม่ได้พัฒนา endpoint `GET /api/reports/sales` ตามโจทย์ Week 13
- AI ไม่ได้ทดสอบ End-to-End กับข้อมูลจริงหรือการใช้งานหลายสาขา และไม่ได้กล่าวอ้างว่าทำการทดสอบดังกล่าวแล้ว
- AI ไม่ได้กรอกผลจริงหรือผล Pass/Fail ของ Test Case แทนผู้ทดสอบ
- AI ไม่ได้ปรับ Requirements Document จากผลทดสอบ Week 13
- AI ไม่ได้ commit หรือ push งานแทนสมาชิกในกลุ่ม

## 5. การตรวจสอบโดยสมาชิกในกลุ่ม

หลังปรับพาธในช่วงนั้น AI รันชุดทดสอบอัตโนมัติ ซึ่งผ่าน **44/44 tests** และตรวจว่า Backend กับ Frontend เปิดได้บนพอร์ตทดสอบ อย่างไรก็ตาม ผลดังกล่าวไม่ได้ยืนยันว่าทดสอบ E2E ครบทุกกรณีตามโจทย์ Week 13

ก่อนส่ง สมาชิกในกลุ่มควรตรวจการเปลี่ยนแปลงในไฟล์จริง รัน E2E Test Cases ตาม Precondition ของแต่ละกรณี รวมถึงกรณีข้ามสาขา แล้วบันทึกผลที่สังเกตได้จริง ผู้จัดทำควรใส่ชื่อผู้ทบทวนและเพิ่มเติมการใช้ AI หรือเครื่องมืออื่นของสมาชิก หากมีข้อมูลที่ยังไม่อยู่ในเอกสารนี้

## 6. ข้อจำกัดและความรับผิดชอบ

คำแนะนำหรือการแก้ไขจาก AI อาจใช้ไม่ได้กับการตั้งค่าและสภาพแวดล้อมของสมาชิกทุกคน ก่อนนำไปใช้จึงควรตรวจสอบกับ Requirement, API contract, โค้ด และฐานข้อมูลของโครงงานอีกครั้ง สมาชิกในกลุ่มยังเป็นผู้ตัดสินใจ รับผิดชอบการทดสอบ และรับผิดชอบผลงานฉบับส่ง

## 7. สรุป

โดยสรุป AI ช่วยตรวจและแก้ปัญหาโครงสร้างกับพาธของโปรเจกต์ ปรับพาธชุดทดสอบ ร่างเอกสาร และตรวจสอบด้วย automated tests แต่ไม่ได้ทำ E2E test แทนผู้ใช้หรือทำงาน Integration ตามโจทย์ Week 13 จนครบ ส่วนการทดสอบและยืนยันผลที่ยังขาด สมาชิกในกลุ่มต้องดำเนินการและบันทึกเอง
